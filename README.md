# Tic-Tac-Toe(Крестики-нолики) (WPF)

Классическая игра "Крестики-нолики" с графическим интерфейсом, реализованная в WPF. 
## Быстрый старт 

### Предварительные требования
- Windows 10/11
- .NET 6.0+
- Visual Studio 2022

### Установка и запуск 
1. Клонируйте репозиторий
   ```bash
   git clone https://github.com/BanCoder/TicTacToe.git
   ```
2. Запустите программу в Visual Studio 2022
   
### Как играть?  
1. Игра начинается автоматически с хода **крестиков**.
2. Поочередно кликайте на пустые ячейки игрового поля.
3. Цель игры - выстроить 3 объекта в ряд по горизонтали, вертикали или диагонали.
4. При победе одного из игровых объектов или ничьей появляется соответствующее уведомление.
5. После завершения игры, поле автоматически сбрасывается для новой партии. 

### Особенности 
- Полноценная реализация игры.
- Автоматическое определение победителя.
- Обработка ничьей.
- Автосброс игры.
- Защита от повторных ходов.

### Архитектура 
- WPF приложение с паттерном MVVM (Model-View-ViewModel).
- Prism Library - для реализации команд и уведомлении об изменении свойств.
