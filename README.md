# Tic-Tac-Toe(Крестики-нолики) (WPF)

Классическая игра "Крестики-нолики" с графическим интерфейсом, реализованная на WPF с архитектурой MVVM.  
## Быстрый старт 🚀

### Предварительные требования ⚙️
- ОС: Windows 10/11
- Платформа: .NET 6.0+
- IDE: Visual Studio 2022

### Установка и запуск 🔧
1. Клонируйте репозиторий
   ```bash
   git clone https://github.com/BanCoder/TicTacToe.git
   cd TicTacToe
   ```
2. Запустите программу в Visual Studio 2022
   
### Как играть? 🎮
1. Игра начинается автоматически с хода **крестиков**
2. Поочередно кликайте на пустые ячейки игрового поля
3. Цель игры - выстроить 3 объекта в ряд по горизонтали, вертикали или диагонали
4. При победе одного из игровых объектов или ничьей появляется соответствующее уведомление
5. После завершения игры, поле автоматически сбрасывается для новой партии

### Особенности ✅
- Полноценная реализация игры
- Автоматическое определение победителя
- Обработка ничьей
- Автосброс игры
- Защита от повторных ходов

### Архитектура 🛠️
#### Технологический стек 💻
- WPF - пользовательский интерфейс
- MVVM - архитектурный паттерн
- Prism Library - реализация команд
#### Основные компоненты 📃
- CellStatus - перечисление состояний ячейк
- CellBtnVm - ViewModel ячейки поля
- MainWindowViewModel - основная логика игры
